# Q3 payment register export

This is a synthetic 100-page payment register for a document-analysis check. Each page contains one record with a gross amount, tax amount, and status. The displayed batch gross total is pending an independent review of all pages.

The export is provided as a multi-picture image: [q3_payment_register_export.mpo](q3_payment_register_export.mpo).

Please report the total gross amount across all 100 records and note any pages you could not read. The figures are synthetic and contain no customer information.
